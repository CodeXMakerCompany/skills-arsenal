# Sharpen

I want a deeper version of this task, not a bigger one. Before rewriting it, do four things:

1. Say what a top practitioner in this field would do here that I am not asking for.
2. Name the rawest material they would start from, instead of what has already been digested for me.
3. Name the specific methods, tools, and measurements they would use.
4. Say what, other than you or me, would show the result is right.

Then rewrite my prompt to ask for exactly that.

Have the rewritten prompt require that any choice a run can settle gets prototyped and recommended from what was observed, not argued. Leave product and preference choices that no run can settle for me to make.

Where the task touches a model call, a cloud resource, or a production path, the rewritten prompt also asks for the cost per request and the limiter behind any number it reports.

Keep the scope the same size. A sharpened task that now needs three times the work was not sharpened, it was inflated. If the honest answer is that the task is already as deep as it needs to be, say that and stop.
