# Bro

Restate your last message. Stop using jargon and speak coherently. State it more simply and more concisely, like one human talking to another.

Rules for the restatement:

- **Say what it means for the person**, not what the system does internally.
- **One idea per sentence.** Short sentences. No subordinate clauses stacked three deep.
- **No jargon, no acronyms, no tool names** unless the person has to type one. Not "the CI pipeline is green", but "the tests pass".
- **Keep every fact.** This is a translation, not a summary, and not a softening. If the news is bad, the plain version is still bad.
- **Name the thing you want them to do**, if there is one, in the last line.
- **No preamble.** Do not say you are restating it. Just say it.

If the original message was already plain, say so in one line rather than padding it out again differently.

Follow the person's language. This skill's voice, not its task, is what **ketchup** borrows when it catches the user up.
